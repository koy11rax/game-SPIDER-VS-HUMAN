# Ночной жилец — готовая сборка для GitHub Pages

Это собранная игра, не архив исходного проекта. Node.js, npm и сборка на GitHub не нужны. Пути относительные: подходит любое имя репозитория.

## Как выложить
1. Распакуйте ZIP на компьютере. Не загружайте сам ZIP вместо его содержимого.
2. Создайте свой репозиторий GitHub и загрузите в его корень всё содержимое архива: index.html, assets, licenses, .github и остальные файлы. index.html должен оказаться в корне, не во вложенной папке.
3. Settings → Pages → Source: **GitHub Actions**.
4. Actions → **Publish game to GitHub Pages** → Run workflow. Если Actions отключены — включите их.
5. После успешного завершения откройте адрес из environment github-pages. Сам факт загрузки файлов ещё не означает публикацию сайта.

Если веб-интерфейс не загрузил скрытую папку .github, создайте файл .github/workflows/pages.yml через Add file → Create new file и вставьте содержимое одноимённого файла из архива. Без этого workflow не появится.

Альтернатива без Actions: Settings → Pages → Deploy from a branch → выберите ветку с файлами и /(root). Файл .nojekyll уже включён. Доступность Pages зависит от настроек аккаунта и репозитория.

Перед публичным размещением подтвердите свои права на распространение ресурсов; сведения находятся в licenses/ASSETS.md. Архив ничего не публикует автоматически и не содержит токенов.

## Управление
WASD — движение; мышь — обзор; клик по игре захватывает указатель.
Shift — бег, Ctrl — осторожное движение; E — взять/положить/сдать кокон.
ПКМ → ЛКМ — прицелиться и закрепить нить; Space — отсоединиться.
Esc — пауза и освобождение указателя. Обычного прыжка нет.
Сдайте три кокона на подстилку, затем войдите пауком в вентиляцию.

Нужен современный браузер с WebGL2 и клавиатура/мышь. Звук начинается после клика. Не открывайте index.html двойным щелчком через file://: моделям нужен HTTP(S). Настройки звука и камеры доступны в игре.

Исходные .blend, видео, node_modules и локальные служебные файлы не включены. Оригинальный проект и lockfile сохранены отдельно на компьютере. Новая публичная ссылка не создавалась; проверка на вашем GitHub Pages ещё не выполнена.
